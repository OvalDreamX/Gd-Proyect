# Space Trucker 0.2.5F7D — Unified Force Test Contract

## Purpose

F7D aligns the force-control regression test with the physical behavior introduced by the unified F7B/F7C actuator allocator. It does not alter production force allocation.

## Confirmed behavior represented by the tests

- Each physical vane receives one bounded scalar output in the unified wrench solution.
- When pitch and roll demands have the same magnitude and sign in the prototype's symmetric four-vane layout, the minimum-force solution uses a diagonally opposed pair. That pair produces both requested torque components while the other two bottom actuators remain eligible but receive zero output.
- If asymmetric damage makes a main-only, torque-balanced baseline physically unattainable, the force-vector telemetry reports the affected actuator forces as `combined`, rather than falsely labeling the complete propulsion-plus-maneuver force as a pure pitch contribution.
- A small residual when summing large, opposing Godot `Vector3` force values is tested with a dedicated 0.1 N tolerance. The observed 0.061 N residual is approximately 7.5e-8 of the 809,325 N main propulsion reference force and is consistent with single-precision vector arithmetic. This does not change simulation force limits or allocator tolerances.

## Test changes

- Replaces the invalid assumption that a combined equal pitch/roll command must produce four nonzero bottom-vane force vectors with checks for the two-actuator diagonal couple, both requested torque components, and all four bottom actuators' eligibility.
- Uses a force-cancellation-specific precision tolerance for pitch/roll diagnostic vector summation; global `EPSILON` remains unchanged.
- Expects `combined` diagnostic force vectors for the damaged asymmetric lift + pitch case, preserving the assertion that all four physical bottom-vane contributions remain visible.

## Scope

Only `tests/flight_force_control_test.gd` changes. No production scripts, force curves, actuator limits, thermal model, or HUD contracts are modified.

## Validation status

The test file was checked for balanced delimiters and expected replacement points. Godot 4.7.2 runtime parsing and execution still require the user's local environment.
