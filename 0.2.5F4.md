# 0.2.5F.4 — Geometry-Aware Actuator Allocator Core

## Added
- Added `VaneActuatorAllocator`, a scene-independent bounded-wrench solver.
- Added support for ship-local `translate_x`, `translate_y`, and `translate_z`
  control-weight channels.
- Added deterministic actuator ordering, per-actuator output bounds, weight-based
  recruitment penalties, validation, achieved-wrench telemetry, and residuals.
- Added focused tests for collective lift, pitch couples, main thrust, three-axis
  translation, eligibility, saturation, and invalid input.

## Changed
- Extended `VaneDefinition` default control-weight schema with three translation
  channels.
- Extended `VaneController` channel validation to recognize those channels.

## Deliberately unchanged
- `RepulsorliftSystem` still uses the existing fixed-group force mapping.
- FCC output and pilot input bindings are unchanged.
- The new allocator is not yet connected to runtime physics. This separation
  allows the solver to be verified before it is allowed to change flight behavior.
