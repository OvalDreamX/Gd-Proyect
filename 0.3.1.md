# Space Trucker — Patch 0.3.1 (Phase 3A: Repository Audit & Environment Contract)

**Milestone:** Phase 3A — Repository audit and environment contract  
**Target engine:** Godot 4.7.2 Stable · GDScript · GL Compatibility  
**Scope:** Documentation and interface contract only (zero gameplay, physics, or scene changes)

---

## Why this patch exists
Per `docs/GDD_ANNEX_v0_3.md` §9 (Phase 3A), before adding planetary/space scenes or hyperspace transitions, all existing gravity, atmosphere, coordinate-frame, HUD, and ship-ownership hooks must be mapped against the live repository.

This milestone also establishes the **parallel-development boundary** so Phase 3 environment/travel work can proceed cleanly while GLB model and armature integration proceeds on `ship.tscn` and `ship_model_*`.

## What was added
- `0.3.1.md` — Root-level milestone summary for human and AI collaborators.
- `docs/PHASE_3A_ENVIRONMENT_CONTRACT.md` — Full Phase 3A repository audit, call-site map, stable Phase 3 IDs, coordinate/unit conventions, and parallel merge boundaries.

## Key findings from the repository audit
1. **Existing reference frame foundation:** `PlanetaryReferenceFrame` (`scripts/planetary_reference_frame.gd`) already supports `FLAT_PLANE` and `SPHERICAL` geometry, orthogonal local `up_world` / `north_world` / `east_world`, radial altitude, and inverse-square spherical gravity.
2. **Existing subsystem wiring:** `PlanetaryGravityBody`, `AtmosphericFlightModel`, `FlightSensorSuite`, `PlayerController`, and `RepulsorliftGroundEffectSystem` already query `PlanetaryReferenceFrame` (typically via `../../PlanetaryReferenceFrame`).
3. **Important space-scene hazard identified:** If `PlanetaryReferenceFrame` is absent from a scene, `PlanetaryGravityBody` leaves `RigidBody3D.gravity_scale = 1.0` (Godot's default 9.8 m/s² downward gravity) and `AtmosphericFlightModel` keeps its exported Earth-like defaults (`atmosphere_enabled = true`, `1.225 kg/m³`, wind). Phase 3B (`0.3.2`) must introduce `EnvironmentProfile` + `EnvironmentManager` so `LOCAL_SPACE` scenes explicitly enforce zero gravity, zero air density, and zero wind.
4. **Ship scene choice for Phase 3:** New Phase 3 environments will instance `res://scenes/ship_ground_effect.tscn` (which inherits `res://scenes/ship.tscn`) so any upstream GLB/armature updates to `ship.tscn` carry over automatically while `scenes/test_range.tscn` stays untouched as the Phase 2 regression scene.
