# 0.2.5F7C — Unified Allocation Corrections

## Baseline

Apply this patch on top of **0.2.5F7A + 0.2.5F7B**. It corrects the F7B unified-allocation integration; it does not replace the geometry allocator or revert the unified physical force model.

## Changes

- Tightened the physical allocator regularization by one order of magnitude so combined saturated lift/yaw demands retain the existing sub-0.01 N residual tolerance.
- Fixed actuator recruitment-weight dilution: unrelated active channels no longer reduce the effective priority of an actuator on channels for which it has no configured weight.
- Reworked damage redistribution to use per-channel shortfall/headroom budgets. A damaged yaw actuator cannot redirect its deficit into unrelated lift or pitch/roll capacity.
- Restored maneuver telemetry's channel-eligible actuator count while keeping the full unified output list available for inspection. The full allocation count is exposed as `unified_eligible_actuator_count`.
- Restored force-vector component semantics through a non-applied main-only reference allocation. The physical ship still receives only the single unified actuator output per vane.
- Clarified the distinction between requested main force telemetry and achieved total physical force telemetry.
- Added `unified_actuator_channel_priority_test.gd` for simultaneous lift/yaw recruitment priority and residual-force checks.
