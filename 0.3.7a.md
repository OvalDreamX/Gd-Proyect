# Space Trucker — Patch 0.3.7a (Ship Tuning Hotfix & Test Regression Fixes)

**Milestone:** Fixes all four headless test failures surfaced after `0.3.7` and dials back radiator efficiency so vacuum overboost genuinely enters `CRITICAL` (`~265°C`) while keeping cold mid-altitude flight as an authentic cooling sweet spot.  
**Target engine:** Godot 4.7.2 Stable · GDScript · GL Compatibility  
**Builds on:** Patch `0.3.7` (drop-in 7-file hotfix before `0.3.8` Simple Planet)

---

## Fixes included

1. **`scripts/vane_controller.gd` — Remove hidden `-20%` cold-thrust cut & fix redistribution telemetry**
   - Removed the unrequested `-20%` cold-strain thrust multiplier in `calculate_authority_multiplier_for_state()` so ships start at full `100%` rated lift (`593,505 N` / `1.10 TWR` / `90.8%` loaded hover throttle) at `-10°C`, while cold strain continues to apply extra thermal wear until warmed up.
   - Fixed `calculate_vane_set_resultant()` to return `allocated_authority_total` as `effective_authority_twr`, restoring FCC damaged-group authority redistribution recovery.
   - Synced fallback thermal/radiator defaults to the dialed-back `ship.json` values.

2. **`data/ships/prototype_freighter/ship.json` — Dialed-back radiator curve & `0.20` maneuver reserve**
   - Set `propulsion.maneuver_boost_at_zero_main_power` back to `0.20` (matching the stock freighter `20%` reserve test).
   - Recalibrated thermal & convective radiator parameters (`base_online_heat_rate = 1.6`, `heat_rate_coefficient = 14.4`, `load_exponent = 2.2`, `vacuum_cooling_coeff = 0.029`, `air_cooling_coeff = 0.042`, `airspeed_cooling_gain = 1.35`, `high_temp_radiation_bonus = 0.011`):
     - **Sea-level stationary `100%` (`+16°C`):** warms into `OVERHEAT` (`~211°C`), nudging pilots to pick up airspeed & altitude.
     - **Tropopause `14 km` `100%` climb (`-58°C`, `~430+ m/s`):** convective radiator cools `>2.3x` faster than vacuum, stabilizing warm green (`~167°C < 185°C`).
     - **Vacuum `100%` push (`-135°C`, `rho = 0`):** climbs into `CRITICAL` (`~265°C`) and wears down to `~75.6%` integrity after `9 minutes` (and `93.0%` after `60 minutes` of green `70%` cruise).

3. **`scripts/repulsorlift_system.gd` & `tests/vane_physics_integration_test.gd`**
   - Restored thin backwards-compatible `apply_collective_lift(field_online, power_output)` wrapper on `RepulsorliftSystem` delegating to `apply_flight_control_forces(..., 90.0, ...)`.
   - Escaped `50%%-effective` format strings in `tests/vane_physics_integration_test.gd` to eliminate Godot's `unsupported format character` error.

4. **`scripts/ship_definition_loader.gd`**
   - Removed premature `or not errors.is_empty()` early return inside `validate()` when `physics`, `cargo`, and `propulsion` are valid `Dictionary` objects, so multi-error manifests always report every field error cleanly (`>= 4` errors in `ship_definition_loader_test.gd`).

5. **`tests/ship_systems_tuning_test.gd`**
   - Isolated `RepulsorliftSystem` from unseated `ShipFlightController` cooling ticks during `_test_max_gross_climb_thermal_headroom` and verified clean `MAX_GROSS` `14 km` acceleration past `435 m/s` over `1.5 s` (`90` frames) with live speed output.
