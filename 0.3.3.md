# Space Trucker — Patch 0.3.3 (Phase 3C: Planetary Test Environment & Starport + 0.3.2 Inertia Fix)

**Milestone:** Phase 3C — Planetary test environment & starport  
**Includes:** Fix for the `0.3.2` `environment_manager_test.gd` `LOCAL_SPACE` linear inertia failure  
**Target engine:** Godot 4.7.2 Stable · GDScript · GL Compatibility  
**Status:** Ready for Godot 4.7.2 headless & desktop runtime verification

---

## Why this patch exists
1. **0.3.2 test fix (`PlanetaryGravityBody`):** Your `0.3.2` run caught a real bug in `environment_manager_test.gd` (`actual 24.66860, expected 24.87521`). Godot's project default `linear_damp = 0.1` (`DAMP_MODE_COMBINE`) was silently bleeding ship speed in `LOCAL_SPACE` even when `AtmosphericFlightModel` disabled air drag. `scripts/planetary_gravity_body.gd` now enforces `linear_damp_mode = RigidBody3D.DAMP_MODE_REPLACE` and `linear_damp = 0.0` whenever `EnvironmentManager` is in `LOCAL_SPACE`, preserving exact Newtonian linear inertia while leaving `test_range.tscn` and `PLANET_SURFACE` flight feel unchanged.
2. **Phase 3C planetary environment (`docs/GDD_ANNEX_v0_3.md` §5.4–5.5 & §9):** Adds `scenes/planet_surface.tscn` — a compact, deterministic low-poly planetary test world separate from `scenes/test_range.tscn` — featuring a flat starport basin, rolling foothills, distant mountain ridges, starport landing pad, control tower, cargo hangar, approach beacons, GL Compatibility sky/fog, and a repeatable `reset_to_starport()` / `Backspace` reset flow.

## What was added
- `0.3.3.md` — Root milestone changelog and verification instructions.
- `scripts/planet_surface_environment.gd` (`PlanetSurfaceEnvironment`) — Builds the deterministic low-poly terrain mesh, coarser static collision mesh, starport buildings, landing pad markings, approach beacons, near-field parallax outcrops, and `reset_to_starport()` recovery.
- `scenes/planet_surface.tscn` — Launchable Phase 3 planetary surface scene (`F6` Run Current Scene in the Godot editor) wired to `EnvironmentManager` (`res://data/environments/test_planet_surface.tres`), spherical `PlanetaryReferenceFrame` (`R = 60,000 m` centered at `(0, -60000, 0)`), `ship_ground_effect.tscn`, and `player.tscn`.
- `tests/planet_surface_environment_test.gd` — Headless `SceneTree` test verifying scene load, spherical gravity/atmosphere wiring, starport pad stability, terrain collision, and `reset_to_starport()`.

## What was updated
- `scripts/planetary_gravity_body.gd` — Preserves original `linear_damp`/`linear_damp_mode` on `test_range.tscn` and `PLANET_SURFACE`, and enforces `DAMP_MODE_REPLACE` + `linear_damp = 0.0` in `LOCAL_SPACE` (and updates dynamically on `environment_profile_changed`).

## Parallel safety with GLB / armature work
- `scenes/ship.tscn`, `scenes/ship_ground_effect.tscn`, `scenes/test_range.tscn`, `scripts/ship_model_*.gd`, `scripts/ship_anchor_registry.gd`, `scripts/ship_definition*.gd`, `scripts/vane_controller.gd`, and `project.godot` were **not modified**.
- `scenes/planet_surface.tscn` instances `res://scenes/ship_ground_effect.tscn`, so any GLB/armature updates to `ship.tscn` carry into the planet scene automatically.

2. Confirm sky/horizon readability, starport pad markings, control tower, hangar, and distant ridges render cleanly in GL Compatibility.
