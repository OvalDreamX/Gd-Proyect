# Space Trucker — 0.2.5F.4 / 0.2.5F.5

## 0.2.5F.4 — Geometry-Aware Actuator Allocator Core

### Added
- Added `VaneActuatorAllocator`, a scene-independent bounded six-axis wrench
  solver for arbitrary bidirectional actuators.
- Added ship-local `translate_x`, `translate_y`, and `translate_z` channels.
- Added per-actuator bounds, control-weight recruitment, input validation,
  achieved-wrench telemetry, and residual reporting.

### Deliberately unchanged
- Runtime flight forces still used the previous fixed-group mapping at F4.
- Translation channels were not bound to pilot input.

## 0.2.5F.5 — Geometry-Based Maneuver Integration

### Fixed
- Replaced the zero-start-only coordinate-descent solve with a regularized
  six-dimensional dual warm start followed by bounded refinement. This fixes
  the stable-ID-dependent output split exposed by the F4 priority regression.
- Added both stable-ID permutations to the control-weight-priority regression;
  the assertion itself remains intact.

### Added
- Exposed each vane's current effective authority, alignment-adjusted thrust
  axis, and eligibility to receive redistributed authority.
- Connected geometry-based allocation to runtime pitch and roll.
- Applied each allocated actuator force at its actual position relative to the
  rigid-body origin, preserving its moment about the current COM.
- Added a dedicated mixed-maneuver debug-vector category.
- Added integration tests for pitch/roll allocation, damage effects,
  redistribution, and runtime discovery of an additional actuator.
- Added complete axis and control-weight metadata to the seven fallback vane
  resources, and explicit zero translation weights to the prototype ship JSON.

### Deliberately unchanged / deferred
- Main-vector propulsion remains on its established path.
- Yaw remains on the legacy side-group path until side-vane geometry can produce
  a verified yaw couple.
- Translation channels remain unbound to pilot controls.


## 0.2.5F.6 — Rated Main-Thrust Regression Fixture

### Fixed
- Stabilized the main-propulsion rated-force test by restoring the main-rear
  vane to 100% integrity and its nominal 60 C temperature immediately before
  measuring its 1.50 gross-TWR output.
- Added explicit assertions for successful fixture setup and nominal
  effective authority before the force assertion.

### Clarified
- The production thermal model was behaving correctly. At the test range's
  -10 C ambient, an unloaded vane's 3 C/s idle heating is slightly below its
  3.5 C/s cooling at 60 C. Earlier test calls therefore moved the main-rear
  vane fractionally below 60 C, correctly applying the cold-authority clamp.
  The original rated-force assertion had not restored its required fixture
  conditions. No production force, thermal, or damage behavior was changed.

## 0.2.5F.7 — Rated Main-Thrust Wear Fixture Correction

### Fixed
- Restored `main_rear` integrity to 100% immediately before the rated main-thrust
  regression measurement, in addition to restoring its temperature to 60 C.
- Added an explicit assertion that the integrity reset succeeds.

### Root cause
- F5.6 reset temperature but did not reset integrity. Earlier online test calls
  accumulated the configured baseline operating wear (`0.000002` integrity/s),
  including calls where the actuator was effectively idle.
- The remaining integrity loss was approximately `2.32e-7`, consistent with
  roughly seven default 60 Hz test steps. Multiplying the nominal `809325 N`
  output by that residual integrity produced the observed `809324.8125 N`.
- The reported `1.50000 TWR` display rounded away this tiny integrity deficit;
  the production force and wear calculations were behaving as configured.

### Deliberately unchanged
- No production physics, thermal rates, wear rates, allocator behavior, or test
  tolerances were changed. The test now establishes the complete nominal fixture
  state it already intended to measure.
